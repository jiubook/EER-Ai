🎯 宝藏基质矩阵视图功能演示

1. 编码系统介绍

矩阵视图使用6位混合编码来表示每种基质组合：

位置 类型 编码范围 说明
第1位 基础属性 0-4 0=敏捷, 1=主能力, 2=力量, 3=意志, 4=智识
第2位 附加属性 0-B 0=攻击, 1=暴击, 2=灼热, ..., B=终结技充能
第3位 技能属性 0-D 0=残暴, 1=迸发, 2=追袭, ..., D=夜幕
第4位 基础等级 1-6 基础属性等级
第5位 附加等级 1-6 附加属性等级
第6位 技能等级 1-3 技能属性等级
示例：编码 40D331 表示： 基础属性=智识(4), 附加属性=攻击(0), 技能属性=夜幕(D), 等级=3-3-1

3. 统计信息
总组合数：90,720 种
计算公式：5(基础) × 12(附加) × 14(技能) × 6(基础等级) × 6(附加等级) × 3(技能等级)
分类 数量 说明
基础属性 5 敏捷、主能力、力量、意志、智识
附加属性 12 攻击、暴击、灼热、治疗、生命、寒冷、法术、自然、物理、源石技艺、电磁、终结技充能
技能属性 14 残暴、迸发、追袭、切骨、强攻、医疗、效益、附术、巧技、粉碎、昂扬、流转、压制、夜幕
基础等级 6 1-6级
附加等级 6 1-6级
技能等级 3 1-3级
4. 功能特性
  • 矩阵可视化：横轴为基础属性，纵轴为附加属性×技能属性
  • 颜色编码：根据等级或稀有度着色，直观显示收集进度
  • 筛选功能：按属性类型、已拥有状态筛选
  • 搜索功能：按编码快速搜索
  • 统计面板：显示总体统计、按属性统计、按武器类型统计
  • 导出功能：支持导出为CSV、JSON、图片格式
  • 悬停提示：显示完整的基质信息
  • 点击详情：查看武器信息和等级
5. 使用示例
// 在 Vue 组件中使用 import { MatrixView, MatrixLegend, MatrixStats } from '@/components/matrix' // 模板 <template> <MatrixView ref="matrixViewRef" style="height: 600px;" /> </template> // 获取矩阵数据 const response = await fetch('/api/profiles/matrix_view') const data = await response.json() // 遍历矩阵 Object.entries(data.matrix).forEach(([code, cell]) => { console.log(`${code}: ${cell.attribute_name} ${cell.attribute_level}`) })
6. API 接口
接口 方法 说明
/api/profiles/matrix_view GET 获取矩阵视图数据
/api/profiles/matrix_stats GET 获取统计信息
/api/profiles/matrix_view_config POST 更新视图配置
7. 扩展功能
  • 热力图模式：用颜色深浅表示拥有率
  • 推荐系统：基于现有组合推荐下一步目标
  • 社区对比：匿名统计全服玩家的拥有情况
  • 历史追踪：记录收集进度趋势
